Extending `SendEnv` with required `AUDITS` field broke `marketing-site/src/app/api/score/delete-me/route.ts:98` where `DeleteMeEnv` (which doesn't carry AUDITS) was being passed to `sendDeletionConfirmEmail(env: SendEnv, ...)`. Resolution: added `AUDITS: R2Bucket` to DeleteMeEnv interface — binding already exists at runtime (R2 bucket is Worker-level). One-line type-only edit; included in §9.2 commit.

**Root cause:** the existing `SendEnv` type is shared across three send functions with different needs:
- `sendGapReportReadyEmail` — link-only, doesn't need AUDITS
